# Artifact Game
This is my fourth time making this game.  This is the game that I use to learn new frameworks.  This one is built in Bevy and Rust.

For the other versions see here:
- [LWJGL (Java)](https://github.com/Drew-Chase/Artifact-Java-Edition)
- [RayLib (C++)](https://github.com/Drew-Chase/artifact_raylib)
- [Unreal Engine (C++)](https://lost-found-interactive.itch.io/artifact-journey-unraveled)

This is just a simple Mario-style 2d side-scrolling platformer.
